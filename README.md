# K-Nearest Neighbors (KNN) Using Python

## About the Project
This project demonstrates the K-Nearest Neighbors (KNN) algorithm, a supervised machine learning algorithm used for classification and regression tasks.

## Concepts Covered
- Introduction to KNN
- KNN Classification
- KNN Regression
- Distance-Based Learning
- Feature Scaling
- StandardScaler
- Train-Test Split
- Model Training and Prediction
- Model Evaluation

## Applications
1. Customer Purchase Prediction
2. House Price Prediction
3. Customer Purchase Prediction Using StandardScaler
4. Employee Promotion Prediction
5. Diabetes Prediction
